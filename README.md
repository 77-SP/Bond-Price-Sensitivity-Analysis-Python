# Bond Price Sensitivity Analysis Using Python

## Overview

A Python-based Fixed Income analysis exploring how changes in market yield affect bond prices.

The project applies **CFA Level I Fixed Income concepts** to a hypothetical 5-year, $1,000 face-value bond with an 8% annual coupon.

## What This Project Covers

* Bond pricing and cash flows
* Yield–price relationship
* Macaulay Duration
* Modified Duration
* Bond price sensitivity
* Estimated vs. actual bond price

## Key Result

When the market yield increased from **8% to 9%**:

* Original bond price: **$1,000.00**
* Estimated price using Modified Duration: **$960.07**
* Actual bond price: **$961.10**

This demonstrates how Modified Duration can be used to approximate the impact of changes in market yield on bond prices.
